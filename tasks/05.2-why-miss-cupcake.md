# Task 5.2: Why Miss Cupcake

Route `/why-miss-cupcake`. Frames: Desktop `6:6`, Tablet `30:231`, Mobile `31:842`. Read [05.0-architecture.md](05.0-architecture.md) first.

## Sections (Desktop order)

1. **"The Simple, Sweet Life"**: centered title, paragraph, "SHOP NOW" → `/#cupcakes`; floating cupcake images around it.
2. **Exploded cupcake**: large image (`7:7`, 802×795) on a cream circle, with **three features** around it, each a round icon + text:
   - "Each and every item produced by Cupcake Boutique is lovingly handmade…"
   - "From the iconic swirl and modern dot to the specially sourced ingredients…"
   - "The recipes are inspired by both authentic local ingredients…"
3. **"Roasted with happiness"**: title, paragraph, "SHOP NOW" → `/#cupcakes`, small decorative images.
4. Footer on the purple band.

Mostly static: the main exercise is **absolute decoration around flow content** and a **feature list placed around a circle** that becomes a plain vertical list on Mobile.

## Decisions (defaults)

- Decorative floating images: `alt=""`, `aria-hidden`, positioned with `position: absolute` inside their section; they must never cover text or buttons at any width. Hide the smallest ones on Mobile if the Mobile frame does.
- Features are a `<ul>` (semantic list), positioned around the image on Tablet/Desktop with CSS Grid areas, not absolute pixel offsets per item.
- No animation (none in the prototype).

## Acceptance criteria

- [x] `/why-miss-cupcake` renders all sections in Figma order; nav item has `aria-current="page"`.
- [x] Both "SHOP NOW" are links to `/#cupcakes`, and the Homepage scrolls to the product grid.

- [x] Desktop/Tablet: features sit around the exploded cupcake as in Figma (±10px); Mobile: stacked vertically as in the Mobile frame.
