# Task 6.0: Clean-up from the 5.x code review

Do this before 6.1–6.5, so the audits in 6.4 / 6.5 run on the final code. Behaviour for the user stays the same except for item 2.

## Changes

1. **Simpler cart limits** (`src/features/cart/cart.ts`, `atoms.ts`, `storage.ts`): replace `MAX_CART_QUANTITY` (derived from `Number.MAX_SAFE_INTEGER`) with a plain `MAX_LINE_QTY = 99` in `src/features/cart/`. Pass it to every `QuantityStepper` as `max` (`+` is `aria-disabled` at 99). Remove the `maxQuantity` parameter threading and `isCanonicalItem`. `sanitizeItems` may return a new array every time, as long as the atom value doesn't loop (check that a `storage` event doesn't cause repeated renders).
2. **Back keeps the scroll position** (`ScrollToHash`): scroll to top only for PUSH/REPLACE navigations (`useNavigationType() !== 'POP'`); on Back/Forward let the browser restore the position. Hash links work as before.
3. **`aria-controls` only when the panel exists** (`Header.tsx`): set `aria-controls={cartOpen ? cartPanelId : undefined}`.
4. **One source for delivery options**: move `deliveryOptions` from `Payment.tsx` and the `Delivery` type from `features/checkout/storage.ts` into `src/data/delivery.ts`; both import from there. `Delivery` is derived from the data (`typeof deliveryOptions[number]['id']`).
5. **Active nav link from the router**: `SiteHeader` takes the current path from `useLocation()`; remove the `currentHref` prop from every page.
6. **Remove the `/ui` demo page**: it was a Task 3 tool and is outdated. Delete `src/pages/UiKit/` and its route in `App.tsx`. Keep every component, asset and data file it imports: all of them are used by real pages (checked: `Header`, `MyBag`, `MapFacade`, `mint-chip.webp` etc. all have other users). Leave the old task files (03, 05.1) as history.
